# 归因分析数据说明

> 模拟数据：公司、商品、渠道、事件均为虚构，用于项目演示和评测。
> 两个数仓均为 SQLite 文件，Python 自带的 sqlite3 即可读取。数据由 `生成脚本/` 中的脚本按固定随机种子生成，可完全复现。

## 一、文件

| 文件 | 内容 | 谁能读 |
| --- | --- | --- |
| ecommerce.db | 场景一：青禾优选电商数仓，2026-07-01 至 2026-09-30 | 归因 Agent |
| fmcg.db | 场景二：禾悦食品快消数仓，2026-04-01 至 2026-09-30 | 归因 Agent |
| 标准答案说明.md | 两个场景埋入的原因、真实影响、干扰项、派生现象、评测口径 | 仅评测，Agent 不得读取 |
| 标准答案_电商GMV.json、标准答案_快消利润率.json | 同上，供评测程序读取 | 仅评测 |
| _impacts_*.json | 反事实计算的原始结果 | 仅评测 |
| 生成脚本/ | gen_ecommerce.py、gen_fmcg.py、make_answers.py | — |

重新生成：`python gen_ecommerce.py 输出目录`，`python gen_fmcg.py 输出目录`，`python make_answers.py 输出目录`。

## 二、场景一：ecommerce.db

演示问题：“9 月 GMV 比 8 月下降了多少？为什么？”

| 表 | 粒度 | 主要字段 |
| --- | --- | --- |
| dim_category | 类目 | category_id, category_name（8 个一级类目） |
| dim_product | 商品 | product_id, product_name, category_id, brand, list_price, cost_price |
| dim_channel | 渠道 | channel_id, channel_name, channel_type（App自然流量、搜索广告、信息流广告、直播、小程序、联盟推广） |
| dim_region | 区域 | region_id, region_name（华南、华东、华北、华中、西南、西北、东北） |
| dim_promotion | 促销活动 | promo_id, promo_name, start_date, end_date, promo_type, category_id（空表示全场）, discount_desc |
| dim_user | 用户 | user_id, user_name, phone, register_date, region_id。**含个人信息，属受限表，分析查询不得访问** |
| fact_traffic_daily | 日 × 渠道 | dt, channel_id, uv（访客数）, detail_uv（商品详情页访客）, cart_uv（加购访客） |
| fact_orders | 订单 | order_id, dt, pay_time, user_id, channel_id, region_id, is_new_user, item_qty, order_amount（原价）, discount_amount, pay_amount（实付）, is_refunded |
| fact_order_items | 订单行 | order_id, product_id, quantity, unit_price, pay_amount（分摊折扣后） |
| fact_inventory_daily | 日 × 商品 | dt, product_id, stock_qty, is_out_of_stock |
| event_calendar | 业务事件 | event_id, start_date, end_date, event_type, title, description, channel_id, category_id |
| meta_metric | 指标字典 | metric_code, metric_name, aliases, definition, decomposition |

指标口径（与 meta_metric 一致）：

| 指标 | 口径 |
| --- | --- |
| GMV（成交额、销售额） | SUM(fact_orders.pay_amount)，含已退款订单 |
| 净 GMV | is_refunded = 0 的订单实付之和 |
| 访客数（UV） | SUM(fact_traffic_daily.uv) |
| 支付转化率 | 订单数 ÷ 访客数 |
| 客单价 | GMV ÷ 订单数 |
| 件单价、每单件数 | GMV ÷ 件数；件数 ÷ 订单数（件数取 fact_orders.item_qty） |
| 毛利 | SUM(fact_order_items.pay_amount − dim_product.cost_price × quantity) |
| 退款率、新客占比 | 已退款订单数 ÷ 订单数；新客订单数 ÷ 订单数 |

拆解关系：GMV = 访客数 × 支付转化率 × 客单价；客单价 = 件单价 × 每单件数。

注意：

1. 渠道的访客数在 fact_traffic_daily，订单在 fact_orders，算分渠道转化率时按 dt 和 channel_id 关联。
2. 类目 GMV 要用 fact_order_items.pay_amount 汇总，fact_orders 上没有类目字段。
3. 日期字段为 `YYYY-MM-DD` 文本，取月份用 `substr(dt, 1, 7)` 或 `strftime('%Y-%m', dt)`。

## 三、场景二：fmcg.db

演示问题：“9 月净利率比 6 月下降了多少个百分点？为什么？”

| 表 | 粒度 | 主要字段 |
| --- | --- | --- |
| dim_sku | SKU | sku_id, sku_name, product_line（果汁饮料、茶饮料、气泡水、坚果零食、膨化零食、乳饮）, spec, list_price, process_cost, launch_date |
| dim_channel | 渠道 | channel_id, channel_name, channel_type, base_discount_rate |
| dim_material | 原材料 | material_id, material_name, unit |
| bom | SKU × 原材料 | sku_id, material_id, qty_per_unit（每件用量） |
| fact_material_price_monthly | 月 × 原材料 | month, material_id, unit_price |
| fact_sku_cost_monthly | 月 × SKU | month, sku_id, unit_material_cost, unit_process_cost, unit_cogs |
| fact_sales_daily | 日 × SKU × 渠道 | dt, sku_id, channel_id, sales_qty, gross_amount（建议零售价金额）, discount_amount, net_revenue |
| fact_logistics_daily | 日 × 渠道 | dt, channel_id, shipped_qty, shipments, logistics_cost |
| dim_channel_commission | 渠道佣金率历史 | channel_id, effective_from, effective_to, commission_rate |
| fact_commission_monthly | 月 × 渠道 | month, channel_id, net_revenue, commission_amount |
| fact_marketing_monthly | 月 × 渠道 | month, channel_id, spend_type, amount |
| event_calendar | 业务事件 | event_id, start_date, end_date, event_type, title, description, channel_id, product_line |
| meta_metric | 指标字典 | 同场景一 |

指标口径：

| 指标 | 口径 |
| --- | --- |
| 营收 | SUM(fact_sales_daily.net_revenue)，已扣折扣 |
| 产品成本 | SUM(sales_qty × 当月 unit_cogs)，按销售月份匹配 fact_sku_cost_monthly |
| 毛利率 | （营收 − 产品成本）÷ 营收 |
| 物流费用、渠道佣金、营销费用 | 分别取 fact_logistics_daily、fact_commission_monthly、fact_marketing_monthly 汇总 |
| 净利率 | （营收 − 产品成本 − 物流费用 − 渠道佣金 − 营销费用）÷ 营收，贡献利润口径，未分摊管理费用和税费 |
| 折扣率 | SUM(discount_amount) ÷ SUM(gross_amount) |

拆解关系：净利率 = 1 − 产品成本率 − 物流费用率 − 佣金率 − 营销费用率（加法模型）；单位成本 = Σ BOM 用量 × 当月材料单价 + 加工费。
